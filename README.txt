# Farida — Uchrashuvga onlayn taklifnoma

## Fayllar
- index.html — asosiy sahifa
- style.css — zamonaviy sariq + ko‘k dizayn
- script.js — musiqa boshqaruvi
- music.mp3 — o‘zingiz joylaydigan fon musiqasi

## O‘zgartirish kerak bo‘lgan joylar
`index.html` ichida:
1. Sana va vaqt
2. Manzil
3. Uchrashuv rejasi 1–2–3
4. Kerak bo‘lsa matnlar

## GitHub Pages
1. Fayllarni GitHub repository'ga yuklang.
2. `Settings → Pages` ga kiring.
3. `Deploy from a branch` ni tanlang.
4. `main` va `/root` ni tanlang.
5. Save bosing.

Musiqa uchun `music.mp3` faylini `index.html` bilan bir papkaga joylang.
